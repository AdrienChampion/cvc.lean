    Bit-vectors over nullables, typed #

    Each lifted operator has its plain counterpart's signature with an Option around every argument and around the result, and nothing else changed. The lift is strict: none unless every argument is some.

    Only the non-indexed operators lift. An indexed one — bvExtract, bvRepeat and the rest — is applied through an Op carrying its indices, and mkNullableLift takes a Kind, so there is no way to express it.
