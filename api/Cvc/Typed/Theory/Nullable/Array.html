    Arrays over nullables, typed #

    Each lifted operator has its plain counterpart's signature with an Option around every argument and around the result, and nothing else changed. The lift is strict: none unless every argument is some.

    select? and store? take and answer nullable terms: it is the array term that becomes nullable, not its indices or elements. An array whose elements are themselves nullable is a different thing, written TotalMap α (Option β).
