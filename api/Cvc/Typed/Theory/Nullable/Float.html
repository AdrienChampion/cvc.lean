    Floating point over nullables, typed #

    Each lifted operator has its plain counterpart's signature with an Option around every argument and around the result, and nothing else changed. The lift is strict: none unless every argument is some.

    A rounding-mode argument becomes nullable along with the rest: fpAdd? takes a Term (Option Float.RoundingMode), since nullable.lift makes every argument of the lifted operator nullable and none of them optional.
