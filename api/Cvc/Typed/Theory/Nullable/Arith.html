    Arithmetic over nullables, typed #

    Each lifted operator has its plain counterpart's signature with an Option around every argument and around the result, so add? : Term (Option α) → Term (Option α) → Env (Term (Option α)) under the same IsArith α. Everything the plain operator checks is checked here.

    The lift is strict: none unless every argument is some.
