    Sets over nullables, typed #

    Each lifted operator has its plain counterpart's signature with an Option around every argument and around the result, and nothing else changed. The lift is strict: none unless every argument is some.

    The set term becomes nullable, not its elements — Option (Set α), not Set (Option α). The element type is untouched, so the Ord binders are the plain operators'.
