    What typed views are built from #

    A typed view takes a term of sort τ apart one level, with its kids typed. Each theory's is indexed by the sort it takes apart — View.Arith : Typ → Type — so that matching on an operator refines the sort, and a kid whose sort the operator does not fix is a Term σ.Denote for a σ : Typ it carries. It is built from the theory's sort-erased view, converting constructor by constructor: the sort-erased view has read the kind, the kids and the indices, and the typed one adds the sorts and the facts about them. def.term_view V, under open Cvc.Typed, gathers them into V : Typ → Type. This module holds what those need.

    A typed view reads sorts, which the library does in Env. A node whose sort no Typ describes, or whose operator the typed view cannot type, is a typed view's none, and the aggregate's other.
