                                                                The DSL's literals for this theory #

                                                                Expanded here rather than in Cvc.Ext so that the grammar a user gets is the grammar of the theories they imported: without this module, smt! does not accept them at all. The expander's own machinery lives in Cvc.Ext, never in Cvc.
