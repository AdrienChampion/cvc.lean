    Arrays #

    The Lean type denoting an SMT array: a default element plus the finitely many indices that differ from it. Indices are held in a Std.TreeMap, so the index type must be ordered.

    Only the Lean side lives here. Turning a total map into a term and back is in Cvc/{Untyped,Typed}/Term/Array.lean, beside the constructors that do it.

    source
    structure Cvc.TotalMap (α β : Type) [Ord α] :
    Type

    A total map from α (the indices) to β (the elements), used to encode SMT-LIB arrays.

    • defaultElem : β

      Default element that all indices not captured by map are mapped to.

    • map : Std.TreeMap α β compare

      Maps indices to elements.
