    Bags #

    The Lean type denoting an SMT bag: a Std.TreeMap from elements to their multiplicity, so the element type must be ordered. A zero multiplicity is not represented, which is what alter keeps true.

    Only the Lean side lives here. Turning a bag into a term and back is in Cvc/{Untyped,Typed}/Term/Bag.lean, beside the constructors that do it.
