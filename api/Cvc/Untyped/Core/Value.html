    Values, sort-erased #

    Two classes relate a Lean type to the terms that denote its values, in the two directions: ValueToTerm α builds a constant term from an α, TermToValue α reads an α back out of one. SrtLike bundles them with ToTyp, which is what a type needs to be usable as a sort at all.

    Only the readers live here — they need nothing but the term. A writer needs its theory's constructor, so each instance is registered in the theory module that can build it, and a consumer that imports one theory does not compile the others.

                  Reading a term's own structure #

                  These say what a term is, as opposed to what value it denotes, and they hold whatever its sort. Reconstructing a container value goes through them: an SMT bag or array is a spine of applications, so reading one back means walking its kind and children.

                  The readers that are tied to a sort — getIntValue, getBitVecValue, and the rest — live in their own theory, beside the constructor that builds what they read.
