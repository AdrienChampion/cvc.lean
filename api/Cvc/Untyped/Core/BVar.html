                              Binding through Lean functions #

                              Binder φ says that φ is the type of a binder's body written as a Lean function: one Term argument per bound variable, ending in Env Term. A lambda (lambdaH) and a quantifier (forallH, existsH) both take one. There is no instance for a bare Env Term, so a body binding no variable does not typecheck.

                              Sort-erased, a variable's sort cannot come from its type, so each is given beside its name, in order. How many are given is a runtime fact, checked against the function's arity before any variable is made.

                              φ is a binder's body taking one Term per bound variable.

                              • arity : Nat

                                How many variables the body binds.

                              • bind : List (String × Srt) → φ → Env (BVars × Term)

                                Creates one bound variable per argument of f, from binders, and applies f to them.

                                Assumes there are exactly arity binders, which bindAll checks.
