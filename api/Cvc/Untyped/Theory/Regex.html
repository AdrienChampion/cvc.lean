                                        SrtLike Regex

                                        • One or more equations did not get rendered due to their size.

                                        regex! #

                                        Regular expressions in the notation they are usually written in, building the same terms as the re… constructors:

                                        regex! ['a'-'z' '_'] ['a'-'z' '0'-'9' '_']*     -- an identifier
regex! digit+ ("." digit+)?                       -- `digit` a regex term in scope
regex! ("ab" | "cd"){2,3} ∖ "abab"
                                        formmeaning
                                        "abc", 'a'the literal string, the literal character
                                        x, ![e]a regex term in scope, any Lean term of the layer's regex type
                                        ., ∅any single character, the empty language (.* is every string)
                                        ['a'-'z' '_'], [^ …]a character class: ranges and characters; its complement in .
                                        r*, r+, r?, r{n}, r{n,m}star, plus, option, exactly n, between n and m
                                        r sconcatenation
                                        ¬ rcomplement
                                        r ∩ s, r ∖ sintersection, difference
                                        r \| sunion

                                        Postfix operators bind tightest, then complement, then concatenation, then ∩/∖, then |, as in the usual notation. A literal string is Lean's, so escapes are Lean's and a "." is a dot, never "any character". No token is added that Lean does not already have.

                                        regex! is scoped in each layer, as smt! is: open Cvc.Untyped selects this one, which answers an Env Term; the typed one answers an Env (Term Regex).
