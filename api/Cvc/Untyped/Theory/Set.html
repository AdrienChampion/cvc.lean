                                                                source
                                                                def Cvc.Untyped.Term.isSetValue [Ω] (term : Term) :
                                                                Bool

                                                                Determine if this term is a set value.

                                                                A term is a set value if it is considered to be a (canonical) constant set value. A canonical set value is one whole AST is:

                                                                (union (singleton c_1) ... (union (singleton c_{n-1}) (singleton c_n))))

                                                                where c_1 ... c_n are values ordered by id such that c_1 > ... > c_n.

                                                                NB: a universe set term (Kind.SET_UNIVERSE) is not considered to be a set value.

                                                                Equations
                                                                • term.isSetValue = (Cvc.Untyped.Term.toUnsafe✝ term).isSetValue

                                                                        Comprehension #

                                                                        { elem | bvs. pred }: a set built by binding variables, so it is written here by hand rather than generated, as quantifiers are. cvc5 supports it only under sets-exp, and its reasoning about one is incomplete: even a membership in a finite comprehension can come back unknown.
