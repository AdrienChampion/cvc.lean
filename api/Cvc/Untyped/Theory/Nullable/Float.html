    Floating point over nullables, sort-erased #

    One lifted constructor per liftable operator, <id>?, each answering none unless every argument is some. That strictness is nullable.lift's semantics and not a choice made here.

    A rounding-mode argument becomes nullable along with the rest: fpAdd? takes a Term (Option Float.RoundingMode), since nullable.lift makes every argument of the lifted operator nullable and none of them optional.
