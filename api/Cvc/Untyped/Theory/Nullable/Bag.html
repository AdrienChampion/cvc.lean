    Bags over nullables, sort-erased #

    One lifted constructor per liftable operator, <id>?, each answering none unless every argument is some. That strictness is nullable.lift's semantics and not a choice made here.

    The bag term becomes nullable, not its elements — Option (Bag α), not Bag (Option α). The element type is untouched, so the Ord binders are the plain operators'.
