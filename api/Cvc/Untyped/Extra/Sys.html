                              structure Cvc.Untyped.Sys.Bmc [Ω] (S : SVars.Sig) [sv : SVars S] (k : Nat) :
                              Type

                              Bounded model checking of a system, unrolled k steps.

                              Holds the system's parts at this scope rather than the Sys itself: a Sys is written once and is generic in the scope, every part taking [Ω], which puts it in Type 1, while a Bmc lives in one scope — it holds a solver and terms — and has to be returned through Env, whose results are in Type. mk instantiates the parts at the scope it runs in.
