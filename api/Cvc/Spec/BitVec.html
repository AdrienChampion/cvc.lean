    From booleans #

    BITVECTOR_FROM_BOOLS builds a bit-vector one bit per argument, so its result's size is its own arity rather than a function of its arguments' sorts. bvFromBool takes a single bit; bvFromBools takes several, and its result size is the term array's, which makes that signature depend on a runtime value.
